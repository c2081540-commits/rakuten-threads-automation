# 感情先行型 家具・インテリア投稿ルール

## 目的
楽天Threadsの商品投稿は、家具の商品説明や「悩み→解決」の説明文ではなく、家具・インテリア好きの投稿者が商品画像を見た時の自然な第一反応を親投稿の中心にする。

## 3分業
1. 親投稿: 見た瞬間の反応、部屋に置いた想像、価格への驚き、色・形への好みで止める。
2. 商品画像: 家具・インテリアを視覚的に理解させる。
3. 返信: サイズ・素材・仕様等の根拠事実を1〜2点補い、PRリンクへつなぐ。

## 商品選定
- 「この家具を友達に見せたら最初に何と言うか」が自然に出る商品を優先する。
- 見た目、画像品質、部屋に置いた想像のしやすさ、価格帯、評価・レビュー、季節性、カテゴリ重複を総合評価する。
- ソファ、チェア、テーブル、照明、ラグ、寝具、収納家具、ミラー、デスク、インテリア雑貨等を中心とする。
- tower、浴室用品、掃除用品、細かな便利グッズは主軸にしない。

## 親投稿
- 感情・反応・部屋想像が主役。
- 楽天商品説明の短縮版にしない。
- 仕様を説明し切らない。
- 「便利そう」「良さそう」「ポイント」だけでは不合格。
- 未所有の商品を買った・使った・届いた等と書かない。

## 返信
- 親の反応を裏付ける商品事実を1〜2点。
- 親と同じ内容を繰り返さない。
- サイズ、素材、色展開、組立、対応条件等から必要な事実だけを短く追加する。

## 非商品投稿
商品投稿の前振りではなく、家具・インテリアそのものの会話として成立させる。
A/B、どっち派、色・配置・照明・ラグ・カーテン・模様替え等を扱う。
一般的な家事あるある、掃除、食事、仕事、便利グッズの話へ戻さない。

## 分析メタデータ
- content_format: furniture_product / interior_engagement / room_idea 等
- furniture_category: ソファ、テーブル、照明、ラグ、寝具、収納家具、ミラー、インテリア雑貨等
- hook_type: discovery / room_imagination / price_hook / comparison / seasonal / wishlist 等
- emotional_reaction / purchase_trigger: 将来生成で必要に応じて保持

## A/B/C
A/B/Cは同じ説明の言い換えではなく、同じ家具から自然に生まれる異なる反応仮説を競わせる。

## 禁止
- 未使用商品の使用体験の捏造
- 「愛用」「買ってよかった」「使ったら」「戻れない」等、所有・使用を前提にする表現
- 架空の家族、友人、口コミ、DM
- 商品ページにない機能や効果
- 類似アカウントの文章コピー
- 旧便利グッズ中心方針への回帰
