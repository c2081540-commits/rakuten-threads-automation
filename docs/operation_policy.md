# 楽天Threads 恒久運営方針

## コンセプト
「楽天で見つけた、部屋に置きたくなる家具・インテリアを紹介する女性アカウント」。
商品を買う予定がない人でも、家具やインテリアを見る目的でフォローしたくなるアカウントを目指す。
家事便利グッズ・収納ハックを主軸には戻さない。

## 投稿者
20代後半〜30代女性。一人暮らし〜二人暮らし。家具・インテリアを見るのが好きな一般ユーザー。高級デザイナーズ専門ではなく、楽天で現実的に買える商品を見る。シンプル、ナチュラル、韓国風、北欧、ホテルライク等を横断する。
未所有商品を「買った」「使っている」「届いた」「うちでは」等と表現しない。「欲しい」「気になる」「これ好き」「部屋に置いたら良さそう」「候補に入れたい」等、見つけた人として書く。

## 読者
20〜40代女性を中心に、模様替え・引っ越し・部屋づくり・家具を見ることが好きな人。InstagramやPinterestでインテリアを見る層、楽天利用者、現実的価格の家具を探す層。

## 商品領域
ソファ、チェア、テーブル、デスク、ベッド・寝具、ラグ、カーテン、照明、ミラー、ドレッサー、シェルフ、キャビネット、テレビボード、小型収納家具、インテリア雑貨、クッション、時計、フラワーベース等。
tower、浴室用品、掃除用品、マグネット収納、細かな便利グッズは主軸から外す。

## 選定基準
レビュー数だけで決めない。見た目、画像品質、Threadsで一目で興味を引くか、部屋に置いた姿を想像できるか、価格、評価、レビュー、季節性、模様替え需要、楽天イベント、カテゴリ重複を総合評価する。
価格帯は数千円、1万円前後、1〜3万円、3〜5万円、それ以上を混ぜる。見るだけでも楽しい商品と買いやすい商品を両方扱う。

## 文章
楽天の商品説明の短縮版を書かない。家具好きの女性が見つけて共有する自然な第一声を親投稿にする。スペックは必要な場合だけ返信側で事実として補う。
切り口は発見、部屋想像、価格驚き、比較、悩み、季節、模様替え、参加型、セール、保存候補などをローテーションする。同じ導入・語尾を連続させない。
「便利そう」「良いかも」だけで成立させない。

## 投稿構成
1日5投稿、7:00 / 12:00 / 15:00 / 18:00 / 21:00を維持する。
7時は軽いインテリア話・参加型、12時と18時は家具発見を中心、15時は比較・価格・候補、21時は照明・寝具・夜に眺めたい家具や部屋づくりを中心にする。ただし完全固定しない。
同日に同カテゴリを過度に重ねない。

## 画像・アフィリエイト
AI生成画像は使わない。楽天APIの商品画像を使用し、画像品質を商品選定で重視する。商品投稿は既存の親投稿＋商品画像、返信で商品事実＋【PR】アフィリエイトURLという正常稼働フローを維持する。

## セール
楽天公式情報で確認できたイベントのみ使用する。存在しない倍率や値引きを作らない。「安いから買え」ではなく、もともと候補だった家具を買うタイミングとして扱う。

## 分析
views / likes / replies / reposts / quotes / sharesを継続取得する。投稿データには可能な範囲で content_format、furniture_category、hook_type 等を持たせ、商品カテゴリ・投稿形式・時間帯を後から比較できるようにする。

## インフラ
Threads API、楽天API、GitHub Actions、GAS dispatch、due判定、history、insights、Secrets等の正常稼働部分は制作方針変更を理由に変更しない。
