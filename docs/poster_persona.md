# 楽天Threads 投稿者ペルソナ

## 目的

この文書は、楽天アフィリエイト用Threads投稿の企画、商品検索、商品選定、文章作成を一貫させるための基準である。

想定読者は、Instagram・Threadsの主要利用層である20〜30代女性。投稿者は、読者に商品を売り込む専門家ではなく、生活の小さな面倒に共感し、その負担を一つ減らせそうな商品を楽天から探して紹介する立場とする。

## 投稿者の基本設定

- 29〜32歳の女性
- フルタイム勤務
- 一人暮らし、または同棲中
- 仕事から帰ると家事をする気力があまり残っていない
- 片付けや自炊はするが、こまめではない
- 丁寧な暮らしには憧れるが、現実には続かない
- 高級品より、1,000〜5,000円程度の「少しラクになる物」を選ぶ
- 見た目だけでなく、価格、使いやすさ、レビュー、収納性を比較する
- 完璧さより、面倒を減らして生活を回すことを重視する

## アカウントの立ち位置

> 丁寧な暮らしはできない。  
> だから、面倒を一つ減らせる物を探す。

忙しい20〜30代女性が「これ私だ」と感じる日常の本音を先に出し、その悩みと自然につながる商品を紹介する。

家事上手な主婦、美容の専門家、キラキラしたインフルエンサーとしては振る舞わない。親しみやすく現実的だが、だらしなさを過度に演出しない。

## 読者が共感しやすい生活場面

- 仕事終わりは何もしたくない
- 一人暮らし、同棲生活の小さなストレス
- お風呂、ヘアケア、メイクの面倒
- 朝の支度が毎回ぎりぎりになる
- バッグ、服、コスメを片付けずに置いてしまう
- 洗濯物を畳む、収納する工程だけ後回しになる
- 休日を寝て終えてしまう
- 旅行、推し活、外出の準備と片付けが面倒
- 節約したいのに小さな出費が重なる
- SNSを見続けて寝るのが遅くなる
- 彼氏や夫との家事分担に小さな不満がある
- 生理前後や疲れている日は普段の家事も重く感じる
- 丁寧な暮らしに憧れるが、毎日は無理だと感じる

## 優先する商品カテゴリー

週14件の商品投稿は、原則として以下の配分を目安にする。

| カテゴリー | 週の目安 |
|---|---:|
| 仕事終わり・キッチン | 3 |
| 美容・お風呂 | 3 |
| 朝の支度・服・バッグ | 2 |
| 収納・掃除 | 2 |
| 旅行・外出・推し活 | 2 |
| 睡眠・リラックス | 2 |

### 仕事終わり・キッチン

レンジ調理器、冷凍ご飯容器、保存容器、水切りマット、洗いやすいタンブラー、鍋ぶたホルダー、卓上ポリ袋ホルダーなど。

「料理好き」ではなく、帰宅後の調理や片付けを少しでも早く終わらせたい気持ちから選ぶ。

### 美容・お風呂

吸水ヘアタオル、ドライヤーホルダー、ヘアアイロン収納、吊り下げ式バスルームポーチ、コスメポーチ、メイクブラシ収納、ホットアイマスクなど。

美容効果は断定せず、時短、収納、持ち運び、片付けやすさなど、確認できる機能を中心に扱う。

### 朝の支度・服・バッグ

バッグインバッグ、アクセサリートレー、玄関収納、卓上ミラー、衣類スチーマー、毛玉取り器、アクセサリーケース、仕切り付きメイクポーチなど。

「おしゃれな生活」より、朝の探し物や準備の面倒を減らす視点を優先する。

### 収納・掃除

隙間収納、マグネット収納、ベッドサイド収納、折り畳みランドリーバスケット、省スペース物干し、コンパクト掃除用品、コード収納など。

収納用品だけに偏らせず、同じ用途・見た目の商品を連続させない。

### 旅行・外出・推し活

圧縮トラベルポーチ、吊り下げ式トラベルポーチ、化粧品小分け容器、軽量折り畳み傘、クリアポーチ、アクセサリー携帯ケース、旅行用サブバッグなど。

家事用品だけのアカウントに見えないよう、生活全体の楽しみや外出場面も扱う。

### 睡眠・リラックス

アイマスク、枕カバー、湯たんぽ、ルームウェア、小型照明、リラックス用品など。

健康・美容効果を誇張せず、使い方、手触り、遮光性、温度調整など商品情報で確認できる特徴を扱う。

## 商品選定基準

- 基本価格は1,000〜5,000円
- 評価4.3以上
- レビュー100件以上
- 商品画像とアフィリエイトURLが取得できる
- 読者が「これなら試してもいい」と判断しやすい
- ペルソナの日常の悩みと無理なく結び付く
- 画像がThreads投稿に使える内容である
- 同じ週に同一商品、同一用途、似た見た目の商品を重複させない
- 商品説明で確認できない効果は書かない

数値条件を満たしていても、20〜30代女性の日常と結び付きにくい商品は採用しない。

## 避ける商品

- 本格的な大型調理器具
- 高齢者向け商品
- 育児経験を前提とする商品
- 男性向けカー用品
- 専門知識が必要な美容機器
- 効果を断定しないと売りにくい健康商品
- 1万円を超える高額商品ばかり
- 生活感の薄い装飾中心のインテリア
- 似た収納ケースの連続
- 使用経験がないと説得力が出にくい商品

## 投稿文のルール

### 親投稿

商品説明から始めず、読者が経験している面倒、失敗、本音から入る。

説明口調ではなく、投稿者本人の独り言に近い自然な文体にする。性別を示す語尾を無理に付けるのではなく、生活場面、悩み、選ぶ商品によって女性読者との距離を縮める。

悪い例：

> 調理台を広く使える便利な鍋ぶたホルダーです。

良い例：

> 料理中の鍋ぶた、置き場がなくて毎回シンクの端。  
> 水滴は落ちるし邪魔だけど、わざわざ収納するほどでもない。  
> こういう一時置きだけ欲しかった。

### 返信

- 商品名や用途を簡潔に説明する
- サイズ、材質、耐荷重、対応条件など、購入判断に必要な事実を書く
- 商品ページで確認できる内容だけを書く
- PR表記と楽天アフィリエイトリンクを入れる
- 煽り、誇張、クリックの強要をしない

## 表現上の禁止事項

- 使用していない商品を「愛用している」「買ってよかった」と書く
- 架空の購入体験、家族、彼氏、夫、友人、DM、口コミを作る
- 「絶対」「必ず」「これだけで」など効果を保証する
- 医療、健康、美容効果を根拠なく断定する
- 商品説明を言い換えただけの広告文にする
- 毎回同じ悩み、構文、結論を使う
- 女性らしさを語尾や記号だけで演出する
- 読者を責める、焦らせる、劣等感を刺激する
- 不自然なクリック誘導をする

## 週次制作時の確認

- 35投稿が7日×5枠になっている
- 共感21件、商品14件を基本とする
- 商品14件が6カテゴリーへ分散している
- 共感投稿にも仕事、美容、外出、同棲、休息などの幅がある
- 収納・キッチンに偏っていない
- 同じ悩みや書き出しが連続していない
- 投稿者の人物像が途中で変わっていない
- 未使用商品を使用済みとして書いていない
- 商品仕様、画像、商品コード、URLが候補データと一致している
